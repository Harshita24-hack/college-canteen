The Courtyard Canteen

A modern and user-friendly campus canteen website designed to make ordering food easier for college students.

Live Website

https://courtyardcanteen.netlify.app/

About the Project

The Courtyard Canteen is a web-based campus food ordering interface where students can explore the canteen menu, add food items to their cart, view the total amount, and place an order.

The website presents everyday college canteen food such as chai, dosa, thali, mains, short eats, and desserts in a simple and attractive interface.

Features

* Browse the canteen menu
* Food items organized into categories
* Add items to cart
* View cart and total price
* Place an order
* Simple and responsive user interface
* Campus-focused food ordering experience

Menu Categories

* Chai & Beverages
* Morning Tiffin
* Mains & Thalis
* Short Eats
* Sweet Endings

Technologies Used

* HTML5
* CSS3
* JavaScript

How to Run the Project

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.

Project Objective

The main objective of this project is to create a simple digital canteen experience that helps students browse food items and place their orders conveniently.
